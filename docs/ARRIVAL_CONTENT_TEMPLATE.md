# 下見カードの確認・登録ひな形（#43 → #44）

実施設の公開準備に使う記録項目です。現在の `src/data/arrivalGuides.ts` はすべて架空の例で、施設確認や写真許諾は完了していません。入口図も位置関係の概念図です。

| 対象           | 人間が記録・確認する項目                                                   |
| -------------- | -------------------------------------------------------------------------- |
| 対象施設       | 正式名称、イベント／施設ID、担当者、公式情報URL                            |
| 車の入口       | 入口固有の位置、施設入口との違い、現地表示、入口への公式地図URL            |
| 歩行者入口     | 車入口と分けた位置・説明。施設の中心座標を車入口に転用しない               |
| 駐車条件       | 形式、サイズ制限、営業時間、時間外入出庫、予約の要否、支払い方法           |
| 手順           | 入庫 → ゲート／駐車券 → 精算 → 退出。各手順の説明と対応写真                |
| 代替駐車場所   | 名称、所在地、条件、確認元。存在と空き状況を区別する                       |
| 項目ごとの根拠 | 施設確認／現地確認等、参照元、確認者、確認日、再確認期限                   |
| 写真           | ファイル・権利者、掲載許諾の記録、利用範囲、期限、クレジット、代替テキスト |
| 承認・更新     | 公開承認者と日時、入口変更／工事／閉鎖時の訂正担当、停止手順               |

不明な値は未確認のまま残します。施設名・入口・手順を写真や一般知識だけから補完しません。人間側の選定・確認・掲載許諾・更新責任の決定は #43／#7／#12 に残ります。

`Evidence<T>` は値、確認状態、確認元、確認日、再確認期限を持ちます。値や根拠・日付が欠ける場合、将来の確認日、期限超過、取り下げ状態では確定情報として使いません。日付は `YYYY-MM-DD`、判定日は日本時間です。

`ArrivalGuide` は車入口と歩行者入口を別々に持ち、条件・手順・代替候補にも項目別の根拠を付けます。`photo.permission` は文章の根拠と別管理です。許諾が有効な画像のみ表示し、画像ロード失敗時は文章を残します。

`availability: 'withdrawn'` はカード全体の表示停止用です。個別の変更は対応する根拠を `unconfirmed` または `withdrawn` にして再確認します。保存済み候補はIDから最新レコードを参照し、古い下見カードをlocalStorageへコピーしません。

管理画面・実データの公開承認・サーバー配信・キャッシュ無効化・実URLの検査は #17／#18／#19／#24／#44 の残作業です。この入力形式だけでは本番の権限や公開制御を提供しません。
