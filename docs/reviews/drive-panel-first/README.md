# ホームをパネル優先にする変更

2026-10-21 / Issue #126 / PR #125。

ホームを開いたら候補パネルが最初に見えるようにしました。以前は出発地カード、趣味、検索条件の説明などが結果より先に並び、候補を見るまで何画面もスクロールが必要でした。

- 一番上に「おすすめ／イベント」、その直下に候補パネル。出発地・趣味・自由入力・気分の条件・イベント検索はパネルの後に配置。
- 下のフォームから検索すると、結果の位置へ移動。待機中・失敗・0件の表示は継続。
- 結果見出し、閉じるボタン、検索条件、入力変更の注意、件数見出し、不足件数の説明を削除。
- 一般／好み順の切り替えと、保存内容による並べ替えを廃止。詳細の好み用操作も撤去し、特徴タグは表示だけに変更。「行きたい」への保存・旧保存データは維持。
- 起動時の現在地＋趣味による一度の検索、手動の検索、重複統合、所要時間表示、詳細と出典は継続。今回の変更による追加の自動検索はない。

## 確認方法

このMacの実API接続版：`http://127.0.0.1:5211/#/`（起動時に検索するため料金が発生します）。無料のサンプル版：`http://127.0.0.1:5210/#/`。

1. ホームで「おすすめ／イベント」の直下にパネルが並ぶことを確認。
2. パネルをタップして詳細・保存を確認。
3. パネルの下へスクロールすると出発地や趣味・検索条件を変更できます。

画像は架空の候補・時間を使った無料テストです。実APIの新しい検索は実行していません。
