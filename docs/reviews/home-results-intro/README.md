# ホームのパネル一覧に検索結果の説明を追加

趣味検索の結果が並ぶ前に、次の短い案内を表示します。

> **好きなことから、次の行き先へ。**
>
> 選んだ趣味をもとに、出発地から片道1〜5時間を目安に、ドライブスポットを探しました。

説明のすぐ下から既存のパネルが並びます。自由記述では「入力した希望をもとに」、条件検索では「選んだ条件に合わせて」に変わり、時間も結果に使われた条件を表示します。趣味未選択の場合は趣味をもとにしたとは表示しません。経路未確認の候補も扱うため、時間は「目安」としています。

## 確認方法

1. 趣味を選んで検索し、ホーム上部の説明とその下のパネルを確認します。
2. 自由記述または「1〜2時間」などの条件で検索すると、説明も検索結果に合わせて変わります。

表示中の結果の条件を使うため、趣味や条件を編集しただけでは説明は変わりません。検索前・候補0件では「探しました」の案内を出しません。旧イベント結果にもこの案内を出しません。

## 検証

- 型チェック・ビルド・整形が成功。
- PC Chromium／スマートフォン幅Chromium／WebKitの検索・趣味設定・検索待ち画面・Brave連携の既存69ケースと、旧イベント画面からの移行6ケースが成功。先頭のパネルが初期表示内にあり、説明直後に並ぶことを確認。
- 開発URL5211で架空の検索応答を使い、趣味・自由記述・条件検索・趣味未選択・未送信の編集・候補0件を確認。
- PC幅と390px幅で画像を確認。320px幅の文字拡大でも横はみ出しなし。
- 検索処理、保存方式、外部送信先を変更していません。確認は架空データで実施し、外部API実行・追加課金なし。公開配信・iPhone実機反映は行っていません。
