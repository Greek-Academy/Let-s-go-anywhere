## 実Firebaseでの確認（2026-10-04）

ユーザーのCLIログイン後、`driveplus-fbc33` の東京・StandardのFirestoreへ `firebase/firestore.rules` だけを反映しました。既存は全拒否ルール・ルートコレクションなしでした。適用前のルールをローカルに退避し、適用後の内容が検証済みファイルと一致することを読み取りで確認しました。

- 実Authに架空の検証アカウントを2つ作成。メール未確認状態の読み書きを拒否。
- 管理APIで検証アカウントだけを確認済みにし、実ブラウザでログイン・本人用リスト1件の作成・編集。別のSDK接続からサーバーの値と改訂番号を取得し、一致を確認。
- もう一方の確認済みアカウントから本人のリストを読もうとする操作・削除しようとする操作を拒否。
- ブラウザのログアウト後、本人のリスト表示が消えることを確認。
- 作成した検証文書1件を削除し、存在しないことを再取得で確認。作成した検証アカウント2件も削除成功。
