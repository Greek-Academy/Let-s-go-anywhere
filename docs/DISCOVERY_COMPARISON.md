# 「見つける」で2社のおすすめを比べる — #97

地域と「気になる場所や、したいこと」を入力すると、OpenAIとClaudeがそれぞれWebを調べ、出典つきの候補カードを表示します。まずMacの開発画面で、費用を抑えて試す段階です。

## 確認する3操作

1. 「探す地域」を都道府県で選び、希望を入力。「探し方：OpenAI・Claudeで比較」のまま「Webで候補を探す」を押します。各社最大10件、合計15〜20件が目標ですが、出典が足りなければ少なくなります。
2. 「すべて／OpenAI／Claude」で切り替え、出典と詳細を確認します。同じ名前・エリアの候補、または同じ名前・出典の候補はまとめ、両社の提案理由と出典を残します。支店名などが違う場合は無理にまとめません。
3. 気になる候補のハートを押し、「好みに寄せたおすすめ」を選びます。カードの「好きなところ」で参考にする特徴を変更できます。保存した候補は「行きたい」から詳細を開けます。

再読み込み後は **「前回の比較結果を開く（無料）」** で、このMacに残した最後の結果を再表示できます。APIへの再検索はありません。希望を変えても、前回の結果であることを明示します。

この比較には「おすすめ」「スポット」が対応します。イベント・今週末や興味チップの絞り込みは従来のサンプル用です。お店の希望は検索欄に書きます。

## 最初は無料で画面を試す

Node.js 24.20.x（`.nvmrc`）と `npm ci` を済ませ、2つのターミナルで起動します。

```bash
# ターミナル1：架空の結果。キーは読まず、APIにも接続しません。
npm run research:demo
```

```bash
# ターミナル2：既存のアプリ
npm run dev -- --host 127.0.0.1 --port 5173 --strictPort
```

確認URL：**http://127.0.0.1:5173/#/discover**

18件の架空カードが表示されます。2社各10件、うち2件が共通という操作確認用データです。写真も実店舗の情報も取得していません。無料サーバーの前回結果はメモリ内だけで、サーバーを止めると消えます。

既に同じポートで動いているサーバーは二重起動しません。実検索／無料サンプルを切り替える場合は検索サーバーだけCtrl+Cで停止して起動し直します。

## キーを設定して実検索する

プロジェクト直下の `.env.research.local` に次の名前で保存します。OpenAIの既存値を消す必要はありません。キー本体はチャット・GitHub・スクリーンショットへ貼りません。

```dotenv
OPENAI_API_KEY=ここにOpenAIキー
ANTHROPIC_API_KEY=ここにAnthropicキー
```

`VITE_` や `DRIVEPLUS_PUBLIC_` には入れません。サンプルサーバーを止めて `npm run research` を起動し、同じ画面を使います。片方のキーがない場合は、両社ともAPIを呼ばずに案内します。キーの追加・変更後は検索サーバーを起動し直してください。

Anthropic側では、必要に応じてAPIコンソールのWeb検索の利用設定も確認します。ChatGPT・Claudeの月額利用料とは別に、APIの残高・請求設定が必要です。追加のチャージを行う前に、これまでの費用と合わせて総額3,000円以内か確認してください。

## 費用の止め方

| 対象 | 制限 |
| --- | --- |
| 新しい比較検索 | このMacの検証台帳全体でまず1回（ユーザーごとではない） |
| APIリクエスト | OpenAI 1回 + Anthropic 1回 |
| Web検索ツール | 各社最大2回 |
| 出力 | 各社最大6,000トークン |
| エラー・タイムアウト | 回数に含む。自動再試行・自動継続・JSON修復の追加APIなし |
| 再表示・保存・詳細・並び替え | APIを呼ばない |

既存の「京都市の公式観光サイト（従来の検索）」は累計3回の別台帳をそのまま使用します。既存回数をリセットしたり、新しい比較を従来の残り回数として扱ったりしません。

比較の回数・両社別の実行記録は `.local-research/comparison-v1/usage.json` に残ります。結果・入力した地域と希望は同ディレクトリの `result.json` に残し、次回無料で開き直すために使います。ファイルはGitの対象外で、Mac内にだけ保存します。検索前に1回分を確保するため、途中でアプリやサーバーを閉じても上限は戻りません。記録が壊れた場合は止め、削除して続行しません。

「検索の結果・待ち時間・参考料金」を開くと各社の件数・モデル・時間・検索回数・参考USDを確認できます。参考額は公開単価による概算で、実請求・為替・税・前払い残高は保証しません。利用量が取れない失敗は「料金未確定」と表示し、0円にしません。実際の請求は両社のUsageで照合してください。

## おすすめはどう変わる？

- **一般的なおすすめ**：今回の地域と希望で取得した結果を、2社交互に表示します。口コミの人気順位ではありません。
- **好みに寄せたおすすめ**：この端末に保存した比較候補の特徴を数え、同じ特徴を持つ候補を上へ並び替えます。4枚ごとに一般順の候補を交ぜ、違う興味にも触れられるようにしています。追加のAI呼び出しはありません。
- ハートの解除で参考から外れます。「このいいねを好み順に使わない」で保存だけ残せます。未反応を「嫌い」として減点しません。
- 「カフェ」「景色」などはAIによる仮の分類です。ユーザーが選んだ特徴もお店の事実確認とは別です。**価格帯は未確認のため好み順に使いません。** 数件のいいねだけで好みを確定したとも表示しません。
- 実検索と架空サンプルのいいねは混ぜません。保存済み候補の説明・分類は保存時点のものを維持します。

価格帯の根拠つき取得、より細かな好みの評価、端末間同期は次の段階です。今の並び替えは精度向上を保証する学習モデルではなく、体験を比較する最小版です。

## データと未確認の扱い

両社へ送るのは「探す地域（都道府県）」と「検索欄の希望」です。出発地点・現在地・学習回答・不安・招待相手・個人のいいね履歴は自動送信しません。検索欄へ入力した内容は両社へ送られるため、個人情報は入れないでください。

「今回のお出かけ条件」の時間・予算・避けたい運転場面は自動送信しません。その条件への適合は未確認のままです。AIによるおすすめを、運転能力・安全性・営業時間・料金・駐車場・空車の確認済み情報へ昇格させません。

比較検索は公開Webを対象にし、施設公式・地域の公式観光サイトを優先する同一指示を両社に送ります。従来の `kyoto.travel` のみという制限は、この比較には適用しません。SNS APIやログインが必要な投稿には接続しません。

検索APIが返した出典URLと候補のURLの対応を確認します。ただし、記載内容の正しさ・閉業・地域・掲載権利を人間が確認済みという意味ではありません。写真やレビューの転載は行いません。詳細には両社の理由と出典を表示します。

いいねと任意の理由は既存の端末内保存に入ります。共有リストに自動送信しません。本人が「リストに追加」で選んだ候補のスナップショットのみ、既存の共有機能で送れます。好みの理由は含みません。

## 処理の流れとコード

```text
探す地域 ＋ 希望 → 検索ボタン
  → Viteの開発用中継 → Macの検索サーバー
  → キー・1回上限を検査して予約
  → OpenAI / Anthropic へ1リクエストずつ
  → 形式・出典の検査 → 重複整理・実行記録 → 結果をMacへ保存
  → 既存カード・詳細・個人保存
  → 端末内のいいねから無料で並び替え
```

| 場所 | 役割 |
| --- | --- |
| `tools/spot-comparison/core.mjs` | 同一プロンプト、2社のリクエスト・応答・出典・使用量、重複整理 |
| `tools/spot-comparison/service.mjs` | 1回上限、API送信、部分失敗、最後の結果の保存 |
| `tools/spot-research/server.mjs` / `build/searchBridge.ts` | 既存サーバーに追加した限定経路。キーはサーバーだけが読む |
| `src/domain/webSearch.ts` / `recommendations.ts` | 型・保存互換性・好みの重み・並び順 |
| `src/components/ComparisonResults.tsx` / `RecommendationFeedback.tsx` | 切り替え、提案元、好きなところ、料金と結果の説明 |
| `tools/discovery-search/tests/comparison.spec.ts` | キー不要のブラウザ操作検証 |

OpenAIは既存の `gpt-5-mini` を維持し、Claudeは費用検証向けに `claude-haiku-4-5-20251001` を使用します。ChatGPT・Claudeアプリ本体のモデルや機能と同じ結果を保証するものではありません。モデル変更時は対応ツールと価格を再確認します。

ClaudeはWeb引用と厳密なJSON出力の同時指定に制限があるため、引用を残した通常の回答文から最終JSONを検査します。読み取れなければ、その会社の失敗として示し、課金される自動修復をしません。
