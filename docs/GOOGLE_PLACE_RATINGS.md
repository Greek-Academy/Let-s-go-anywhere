# スポットのGoogle評価を表示する

関連Issue：[#148](https://github.com/Greek-Academy/Let-s-go-anywhere/issues/148)

## 何ができるか

AI検索のパネルと詳細画面に、Googleの星評価・口コミ件数を表示します。評価の行を押すと、その施設のGoogle Mapsページを別タブで開きます。評価を取得できない候補も、名前・趣味・所要時間はそのまま表示します。

星評価はAIに作らせません。Braveで情報を集め、Geminiで候補を整理し、Routesで時間条件を確認した**後**、表示対象の最大10件だけをGoogle Places API (New)で調べます。Google検索の関連候補バーは追加しません。評価順に並べ替える変更もありません。

## 施設の取り違えを防ぐ

- 候補の名前と地域を使ってText Searchを1回実行します。写真や口コミ本文は要求しません。
- 名前は空白などの表記差を除いて完全一致を要求します。都道府県と市区町村も照合し、日本の施設で一致するものが1つだけある場合に採用します。
- 同名の別店舗、地域情報の不足、複数の一致、未評価・口コミ0件、壊れた応答、通信エラーでは評価を表示しません。候補自体は除外しません。
- 正式名と通称が違う場所など、実在する施設でも評価が出ないことがあります。表示数のために曖昧な一致を採用しません。

## 設定と通信

Macのローカル検索サーバーは、既存の `.env.photos.local` にある `GOOGLE_PLACES_API_KEY` を読みます。写真試用の固定3施設や利用済み記録は変更しません。キーはサーバー内でだけ使用し、ブラウザ・URL・ログには渡しません。

キーにはPlaces API (New)を使える設定が必要です。設定がない場合もAI検索は動き、評価だけを省略します。キー変更は検索サーバーの再起動で反映します。[Brave検索の起動手順](BRAVE_SEARCH_TRIAL.md)と同じコマンドで起動できます。

Google Placesに送るのは候補の名前・地域です。この評価処理からユーザーの現在地座標や趣味を送ることはありません。評価のためにGeminiやBraveを追加で呼びません。最大5件を同時に処理し、全体を8秒で打ち切ります。未開始分は省略し、自動再試行しません。検索全体の30秒以内を保証するものではありません。

## 保存・表示

評価・件数・Google Mapsリンク・第三者の帰属表示は、現在の画面のメモリ内で最大10分利用します。その後は非表示になり、自動では再取得しません。新しい検索では改めて取得します。

「行きたい」、共有候補、検索結果の保存ファイルにこれらを残しません。アプリの再読み込み後、保存済み候補に古い評価が残ることはありません。サーバーの使用量記録には試行・一致・取得不可・失敗・未試行の件数だけを追加します。Googleの生の応答は保存しません。

評価のすぐ隣に `Google Maps` を表示します。Googleから第三者の帰属情報が返った場合も併記します。表示場所やフォントは[GoogleのPlaces表示ポリシー](https://developers.google.com/maps/documentation/places/web-service/policies)に合わせます。

## 追加費用

`rating` と `userRatingCount` を取得するため、Text Search Enterpriseの料金区分になります。2026-11-11確認時の公式料金では月1,000回の無料枠があり、最初の有料段階は1,000回あたり35米ドルです。1検索で10件取得する場合、無料枠適用前の目安は**0.35米ドル**です。Googleの請求アカウントの他の利用状況、税金などで実際の請求は変わります。Brave・Gemini・Routesの料金は別です。

再検索の総回数制限は追加していません。使用量記録は送信を試みた件数で、請求額そのものではありません。正確な利用量・請求はGoogle Cloudで確認します。

- [Text Searchの項目と料金区分](https://developers.google.com/maps/documentation/places/web-service/text-search)
- [Google Maps Platform料金表](https://developers.google.com/maps/billing-and-pricing/pricing)

## 確認する操作

1. ホームで新しくAI検索し、取得できた候補に星評価・件数が表示されることを確認します。
2. 評価の行を押し、対応するGoogle Mapsの施設を開けることを確認します。名前・写真を押すと従来の詳細画面に進みます。
3. 「行きたい」に保存して再読み込みすると、候補は残り、評価は保存されていないことを確認します。

PC・スマートフォン幅のブラウザで確認しています。公開Web・実機iPhoneへのデプロイは含みません。[画面と検証記録](reviews/google-ratings/README.md)を参照してください。
