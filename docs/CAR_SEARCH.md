# 車を探す：京都の実地図・公開拠点データ

2026-09-29 / Issue #75。#21・#22・#24の小規模な先行実装です。

「車を探す」タブを開くと、**道路を見やすく描いた京都の実地図と、OpenStreetMapに登録された京都中心部の10件**を表示します。架空のピンではありません。ただし、運営や事業者による現在の営業確認はまだ行っていません。

ブラウザ：`http://127.0.0.1:5173/#/cars`。`npm run dev` で起動します。iPhone：`npm run ios:sync` → Xcodeで起動。APIキー・検索サーバーは不要です。

[画面と確認手順](reviews/car-search-links/README.md)

## できること

- 指で地図を移動、2本指または＋／−で拡大縮小。PCではドラッグと＋／−。
- 京都中心部・京都駅・四条烏丸・烏丸御池・三条京阪の地域検索。「このエリアで検索」は現在表示している範囲に絞る操作です。
- レンタカー／カーシェアと事業者で絞り込み、地図／一覧を切り替える。
- ピン→下から出る拠点カード→詳細→保存。保存先は「行きたい」の「車候補」です。
- 拠点の出典を開く。対応する事業者の公式検索や、外部地図で公開座標を確認する。
- 地図は同梱の道路・川・公園データを描画。地図操作で外部サーバーへ通信しない。

地図を移動するだけでは検索範囲を変更しません。「移動したエリアで検索」を押した範囲を使います。地図と一覧は同じ条件です。範囲・ズーム・選択拠点・種別・事業者は端末に保持されます。

検索は取得済みの京都データだけを対象にします。大阪などの未対応地域は0件と掲載範囲を案内し、外部検索へ進めます。GPS現在地は取得しません。地図の中心を現在地と偽って表示しません。

## 表示の意味

| 表示項目                         | 情報の扱い                                               |
| -------------------------------- | -------------------------------------------------------- |
| 名称・種別・緯度経度             | OpenStreetMapへの投稿情報。運営の現地確認とは別          |
| 地図背景                         | OpenStreetMapの同梱ベクターデータを描画                       |
| データ取得日                     | 2026-09-29。営業の確認日ではない                         |
| 住所・営業時間・入出庫・車両条件 | 未確認。公式で確認                                       |
| 空き状況・料金・予約可否         | 未取得。推定しない                                       |
| 投稿データの確認日・営業時間     | 詳細の折りたたみに元表記のみ表示。現在の事実と認定しない |
| 保存                             | 自分の端末内の候補。予約にはならない                     |

8件のレンタカー、2件のカーシェアを同梱しています。ピンがない地域に拠点が存在しないという意味ではありません。近接するピンは地図を拡大するか一覧から選べます。公式拠点ページを確認できたかのようなリンクは作りません。

旧サンプル地図は「出典・掲載範囲」→「以前のサンプル地図を見る」（`/#/cars/sample`）で開けます。旧サンプル車候補とその保存は保持し、外部への架空の所在地案内は引き続き禁止します。コンテンツ確認ツール内のプレビューはサンプル地図を使用します。

## 情報源と費用

今回の構成で追加のサービス契約・API利用料は**0円**です。OpenAI APIは使用しません。外部サイトを開くときはインターネット接続が必要です。iPhone版の地図そのものは同梱データで表示できます。

### 地図：京都のOpenStreetMapデータを独自の配色で描画

LUUPのように道路・拠点を見やすくするため、国土地理院の完成済み画像から、**同梱のベクターデータをLeaflet Canvasで描く方式**へ変更しました。LUUPの地図画像や独自素材は使用していません。

- 背景は淡いグリーン、道路は白、川は淡い青、公園は緑。主要道路を太めに描き、小さい道は拡大時に表示します。
- 細かい建物・店舗名は省略し、駅名と一部の通り名だけを表示。道路・川の線幅は見やすさのための表現で、実際の幅や運転のしやすさを示しません。
- 背景の取得範囲は緯度34.965〜35.04、経度135.72〜135.80。拠点の掲載範囲は従来どおり京都中心部の10件です。拠点検索の対象地域を増やしたものではありません。
- 拡大縮小は13〜18（画面サイズにより最低ズームを調整）。移動をデータ範囲内に制限し、範囲外を架空の道路で補いません。
- 初回Web表示では自分の配信元からデータを読み込みます。iPhoneには同梱します。表示・移動・拡大時に地図サービスへの通信や従量課金はありません。APIキーも不要です。

データは `src/data/kyoto-basemap.geo.json`（約4 MB、圧縮配信時は約0.75 MB）。取得日・基準時刻・範囲・取得クエリ・元データのSHA256・加工内容は `src/data/kyoto-basemap.meta.json` に記録しています。2026-09-29取得。道路、地上の鉄道、水域・川、公園、駅の14,097要素を収録。更新は手動です。

[OSMの利用条件](https://www.openstreetmap.org/copyright)に従い、アプリで帰属表示とODbLの案内を常時表示し、同じライセンスの加工データを提供します。「出典・掲載範囲」からWebではダウンロード、iPhoneでは配布データのリンクを開けます。表示ライブラリLeaflet 1.9.4のBSD 2-Clauseライセンスも同梱しています。

地図データの変換は開発時だけ行います。公開Overpassへ実行時にアクセスしません。取得クエリを3回に分けた正常応答を要素のtype/idで統合し、基準時刻を記録した後、次の順で変換しました（アプリの起動には不要）。初期の広い複合クエリはタイムアウトし、範囲・内容を限定して取得しました。

```sh
# combined.osm.json: 元応答をtype/idで統合したJSON
# queries.overpass: 実行した3つのクエリ（meta.jsonにも全文を記録）
npm exec --yes --package=osmtogeojson@3.0.0-beta.5 -- osmtogeojson -m combined.osm.json > combined.geojson
node scripts/prepare-kyoto-basemap.mjs combined.osm.json combined.geojson queries.overpass
```

変換は不要タグの除去・表示対象の抽出です。地物のOSM IDと座標を残し、架空の線を足していません。経路案内、一方通行・通行制限、工事、車の入口などを判断するナビではありません。本公開や対象拡大時は更新頻度・容量・運用を再検討します。

### 拠点：OpenStreetMap

[著作権・ODbLの案内](https://www.openstreetmap.org/copyright)に従い、© OpenStreetMap contributorsとODbLへの案内を表示します。名称整形・事業者分類を施した派生データにもODbL 1.0を適用します。アプリコードや他のサンプルカタログとはデータを分離しています。

元データは `src/data/kyoto-car-stations.osm.json`、表示用変換は `src/domain/realStations.ts` です。アプリの「出典・掲載範囲」に元データと表示用JSONを表示し、Webでは元データをダウンロードできます。元JSONはビルド成果物にも同梱します。

取得先：Overpass API公開インスタンス `https://overpass-api.de/api/interpreter`。取得したOSMデータの基準時刻は `2026-09-29T10:23:45Z`。取得クエリ：

```overpass
[out:json][timeout:25];
nwr["amenity"~"^(car_rental|car_sharing)$"](34.974,135.738,35.025,135.781);
out center;
```

[Overpassの利用指針](https://dev.overpass-api.de/overpass-doc/en/preface/commons.html)を確認し、**開発時の一度の取得**に使用しました。アプリからOverpassへ検索・定期通信はしません。建物・区画のデータは中心座標であり、車の入口の位置を保証しません。事業者の写真・ロゴ・Web店舗一覧は転載していません。

## 通信と端末保存

- 地図・拠点の表示は同梱データです。地図サービスへの検索・タイル通信、GPSの取得は行いません。
- 静的配信のCSPから国土地理院向けの画像許可を削除し、`connect-src 'none'` を維持します。外部リンクは利用者が開いた場合にだけ遷移します。
- 地図ライブラリと背景データは「車を探す」の地図が必要なときに読み込みます。
- 保存は既存のlocalStorage／Capacitor Preferences。状態 `realMap` と `carSearch` がない過去データには初期値を補います。既存の行きたい・メモ・サンプル車候補は残します。旧版へ戻した場合に未知項目の保存保護が働くときは、データを削除せず新しい版へ戻してください。

## 外部検索

掲載外の地域や事業者は `/#/cars/search` から探せます。入力地域＋種別または事業者名でGoogleマップを検索します。確認画面でURLを押すまで、検索語は送りません。公式検索は固定の入口を開き、地域・日時は移動先で入力します。対応先は[タイムズカー](https://share.timescar.jp/place/)、[トヨタレンタカー](https://rent.toyota.co.jp/shop/)、[オリックスレンタカー](https://car.orix.co.jp/shop/)、[ニッポンレンタカー](https://store.nipponrentacar.co.jp/b/nrs/)です。

公式へのリンクは拠点の営業確認や、拠点データの転載許諾を得たことを意味しません。iPhoneではブラウザ画面を閉じるとアプリへ戻れます。
