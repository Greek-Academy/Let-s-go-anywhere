# 車を探す：4地域と現在地からの検索検証

> 2026-10-01追記：#83で全国の登録2,927件へ拡張しました。最新の掲載範囲・確認方法は [全国の拠点検索](NATIONAL_STATIONS.md) を参照してください。以下の4地域・45件の範囲は初回検証時の記録です。現在地の許可・一時利用・消去の仕組みは継続します。

2026-09-30 / Issue #79（PR #78を土台にした追加）。[現在地検索の確認手順](LOCATION_SEARCH.md)、[前段の地図検証・実測](reviews/map-pilot/README.md)。

「車を探す」は国土地理院のベクトルタイルを表示範囲ごとに取得し、白い道路・淡い青の川・控えめな駅名に加工します。拠点はOSM公開情報の京都10件、梅田5件、草津3件、新宿・中野27件を同梱します。現在の営業・空車を確認済みの一覧ではありません。

## 仕組み

```text
画面を動かす / 拡大する
  → Leafletが必要な区画を決める
  → 端末内の一時キャッシュを確認
  → 未取得の区画だけ国土地理院からPBF形式で取得
  → 道路・川・鉄道・地名を端末で描画

拠点ピン / 絞り込み / 一覧
  → アプリに同梱した45件の公開情報から抽出
  → 詳細・未確認事項 → 車候補に保存
  → 必要に応じて利用者が公式サービスを開く
```

背景と拠点は別です。地図を他地域へ動かしても、その地域の拠点を自動取得するわけではありません。「このエリアで検索」は取得済み18件を表示中の範囲に絞ります。0件は実際に拠点が存在しないという意味ではありません。

地域名の検索は4地域と京都内のプリセットだけです。明示的な操作・許可により一度だけ現在地を取得し、約2km以内の掲載拠点を直線距離順に表示できます。全国の住所検索・ナビはありません。保存先はlocalStorage / Capacitor Preferencesで、既存の行きたい・車候補・メモを維持します。GPS由来の位置・範囲は永続保存しません。

## 背景地図の情報源

- [国土地理院ベクトルタイル提供実験](https://github.com/gsi-cyberjapan/gsimaps-vector-experiment)。背景地図を加工して利用している旨を常時表示します。[利用条件](https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html)。提供実験であり、仕様変更・提供停止の可能性があります。
- 取得先：`https://cyberjapandata.gsi.go.jp/xyz/experimental_bvmap/{z}/{x}/{y}.pbf`。
- GSIの512pxタイルのズームは、Leaflet標準256pxのズームより1小さくなります。`tileSize:512`、取得時 `z = Leaflet z - 1`。Leafletで12〜18、ソース上限16を超える場合は拡大表示です。
- Leaflet 1.9.4、`@mapbox/vector-tile` 3.0.0、`pbf` 5.1.2。ライセンスはアプリ「出典・掲載範囲」で表示します。
- 実装：`src/components/VectorBasemap.ts`、`src/domain/mapTiles.ts`。
- 地図上の線幅は見やすさのための描画で、実際の道幅・通行可否・運転の難しさではありません。建物・公園の詳細・一部の地名は省略します。道路情報から安全判定しません。

以前の京都全体GeoJSON（約4 MB）は参照用としてリポジトリに残していますが、この画面の配信・iPhone成果物には含めません。[PR #76時点の記録](reviews/car-search-links/README.md)とは通信・背景地図の仕様が変わりました。

## 拠点の取得と更新

[OSM / ODbL](https://www.openstreetmap.org/copyright)の名称・位置・種別を使います。raw JSONと表示用データをアプリで閲覧でき、元データの配布リンクも用意しています。元・派生データはODbL 1.0。事業者のロゴ・写真・公式店舗一覧の転載はしていません。

| 地域 | 件数 | アプリのファイル | 取得方法 |
| --- | ---: | --- | --- |
| 京都中心部 | 10 | `src/data/kyoto-car-stations.osm.json` | 2026-09-29、Overpass bbox 34.974,135.738,35.025,135.781 |
| 大阪・梅田 | 5 | `src/data/umeda-car-stations.osm.json` | 2026-09-30、OSM API map extract（下記） |
| 滋賀・草津 | 3 | `src/data/kusatsu-car-stations.osm.json` | 2026-09-30、Overpass bbox 34.993,135.945,35.035,135.978 |
| 新宿・中野 | 27 | `src/data/shinjuku-car-stations.osm.json` | 2026-09-30、Overpass bbox 35.685,139.665,35.720,139.715 |

京都・草津・新宿は開発時に `nwr[amenity~"^(car_rental|car_sharing)$"](bbox);out center;` で限定範囲を取得しました。基準時刻は各JSONの `osm3s.timestamp_osm_base`。取得日と基準時刻は別です。新宿の追加は[現在地検証の取得記録](LOCATION_SEARCH.md)を参照してください。

梅田はOverpassのタイムアウト後、[OSM APIの小範囲map extract](https://api.openstreetmap.org/api/0.6/map?bbox=135.49,34.695,135.505,34.71)を1回取得。XMLから `amenity=car_rental/car_sharing` の5要素だけを抽出しました。wayの位置は構成点の緯度経度の平均です。JSONの基準時刻欄はこの応答のHTTP Dateで、Overpassと同じスナップショット整合性を示す値ではありません。元の取得先URLと加工内容はJSONに記録しています。

**アプリからOSM API / Overpassへ検索・定期取得しません。** 全国分の自動収集や、公開サービスの実行時検索基盤にはしていません。

種別はOSMのamenityタグによります。梅田には名称が「タイムズカーシェア」でもcar_rentalとして登録された要素があり、情報品質の確認は残ります。建物中心と車の入口も別です。営業時間・住所・空車・料金・車両条件は未確認または未取得と表示します。データの取得日を営業確認日と混同しません。

更新時は限定範囲の再取得→件数・座標・名称・種別・追加削除・既存保存IDへの影響確認→取得日とテスト更新→PRレビューの順です。現在は自動更新しません。

## 通信・キャッシュ・失敗時

- 表示範囲の区画番号と接続元IPなどは国土地理院へ伝わり、閲覧地域を推測できます。GPS座標そのもの・プロフィール・学習回答・相談メモをアプリから送信しません。CookieとRefererは付けません。
- 静的CSPの `connect-src` は国土地理院の上記タイルディレクトリだけ許可。検索APIや任意ホストへ広く許可していません。`scripts/verify-preview.mjs` は従来の通信禁止版またはこの限定許可版だけを受け入れます。
- 可視範囲に必要な区画を取得。範囲外の先読みはせず、移動中の更新を控え、ズーム終了後に取得します。不要になった要求は中断し、同じURLへの同時要求を共有します。
- PBF本文のLRUキャッシュ上限8 MiB、有効期間15分。1応答は最大4 MiB、タイムアウト12秒。描画用Canvasなどを含めたアプリ全体のメモリ上限ではありません。ブラウザ自身のHTTPキャッシュは別です。
- キャッシュはプロセス内のみです。再起動・期限切れ・追い出し後は通信が必要です。iPhoneでも全国地図のオフライン利用を保証しません。
- 通信・デコードに失敗すると案内と「地図を再読み込み」を表示。取得済み拠点の一覧・詳細・保存は使えます。架空の背景や空車情報で補いません。
- ローカル計測は取得完了した本文サイズ・要求回数・再利用数だけで、外部送信しません。正確な通信課金計測ではありません。

## 費用と次の判断

今回の追加契約・API利用料は0円。OpenAI API・有料地図サービス・新しいサーバーは使っていません。実測と将来の通信規模の例は[確認資料](reviews/map-pilot/README.md#費用の判断)にあります。

地図は国土地理院から端末へ直接配信されます。現方式でその本文分の自社配信費が発生するわけではありません。一方、公開アプリ自身の配信、全国の拠点データ取得・更新、提供実験の継続性、有料サービスや独自配信へ切り替えた場合の費用は別途評価します。「全国運用まで無料・安定」との結論にはしていません。

人間側は現在地の許可と近隣候補の見え方を実機で確認してください。APIキーは不要です。本公開前に対象地域・必要な拠点範囲・情報確認担当・更新頻度を決定し、利用条件と公開規模を確認します（#8）。開発側はその条件で#21・#22の全国対応・更新基盤・配信方式を詰めます。空車・予約APIの利用は別途事業者との確認が必要です。

公式検索・外部地図は従来どおり確認画面から開きます。公式へのリンクは、その拠点の営業・掲載・予約可否を検証したという意味ではありません。
