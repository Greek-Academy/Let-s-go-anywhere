# 車を探す：実際の検索への入口

2026-09-29 / Issue #75。#21・#22・#24の先行部分です。

「車を探す」の地図・一覧 → **実際の車を探す** → 駅・地域と種別・事業者を選ぶ → **外部地図で車を探す** → 移動先を確認 → Googleマップで検索、の順に操作できます。

ブラウザの確認URL：`http://127.0.0.1:5173/#/cars`。開発サーバーは `npm run dev` で起動します。入力画面の直接URLは `http://127.0.0.1:5173/#/cars/search` です。

iPhoneは `npm run ios:sync` でWeb画面を取り込み、Xcodeで起動します。端末のブラウザ画面が開き、閉じるとアプリへ戻れます。APIキー・検索サーバーの起動は不要です。

## できることと表示の意味

- 外部地図：入力した地域＋種別または事業者名を検索語にします。「京都駅」「トヨタレンタカー」なら検索語は「京都駅 トヨタレンタカー」です。検索結果はGoogle側の表示であり、アプリが拠点の存在・検索条件への厳密な一致・営業・空き状況を確認したものではありません。
- 公式サイト：タイムズカー／トヨタレンタカー／オリックスレンタカー／ニッポンレンタカーの検索入口を開きます。駅・地域や日時は公式サイトで入力します。公式が公開していない検索パラメーターを推測して渡しません。
- 条件保持：地域・種別・事業者は端末内に保存します。初回はプロフィールの出発エリアを使い、後から「出発エリアを使う」で入れ直せます。サンプル地図に入力した駅・地域から開いた場合は、その入力を渡します。再び地図の入力から開けば、その入力が優先されます。
- 元の地図・ピン・車候補はサンプルのままです。架空拠点の「公式」「外部地図」リンクを実際の場所へ変更しません。サンプル車候補の保存も引き続き使えます。外部の検索結果をアプリの車候補へ取り込む機能は未実装です。

## 費用・通信・保存

この導線の追加サービス費用は0円です。地図SDKや場所検索APIを呼ばず、APIキー不要の[Google Maps URLs](https://developers.google.com/maps/documentation/urls/get-started)を使用します。OpenAI APIは使用しません。外部での車の予約・利用にかかる料金は各社で確認してください。

入力だけで外部通信はしません。確認画面でリンクを開いたとき、Googleへ表示済みの検索語を送ります。公式検索入口には地域を送信しません。プロフィール全体・学習回答・相談メモはURLに付けません。地図表示後の通信・権限要求・検索順位等は外部サービスが扱います。

新しい状態 `carSearch` はWebではlocalStorage、iPhoneでは既存のCapacitor Preferencesに保存します。既存の保存ファイルにこの項目がなくても初期値を補い、行きたい・車候補・メモを残します。以前の版へ戻した場合は未知の項目に対する既存の上書き保護が働き、自動保存が停止することがあります。保存データを削除せず、新しい版に戻してください。
