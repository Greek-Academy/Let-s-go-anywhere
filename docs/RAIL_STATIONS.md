# 駅を選んでお店・スポットを探す

Issue #104。出発地と、探したい場所を駅単位で選びます。都道府県選択と「すべての地域」は「見つける」から外しました。

## 利用者の操作

1. 初回設定の「出発する最寄駅」に「しんじゅ」などを入力し、表示された駅を選びます。スキップもできます。後からホーム上部の出発エリア、またはプロフィールで変更できます。
2. 「見つける」の「探す地域」で「出発駅の周辺」、または別の駅を選びます。「この駅の周辺で探す」で確定するまでは検索先を変更しません。
3. ジャンル（例：自然）または希望文を指定し、「Webで候補を探す」を押します。駅周辺を条件としてOpenAI・Claudeへ送ります。候補の入力・選択だけではAI検索しません。

駅の代表位置から約2kmを検索の目安にしています。実際の候補との距離を測定して絞り込む機能ではなく、徒歩・車の所要時間も未確認です。候補の住所と出典を確認してください。候補数を埋めるために別の駅や都道府県全域へ自動で広げません。

同名駅は都道府県・路線を併記します。漢字・ひらがな・カタカナ・全角半角に対応し、完全一致、前方一致、部分一致の順に最大20件表示します。日本語の駅名・読みが対象で、英字表記や旧駅名の全件対応は含みません。上下キー・Enterでも選べます。

## 保存と検索の仕組み

```text
入力文字 → 同梱した駅データを検索 → 候補から駅IDを選択
                                         ↓
  出発駅：profile.stationId     探す駅：discover.stationId
                                         ↓
                「Webで候補を探す」を押したときだけ送信
                                         ↓
                サーバーも同じ駅データで駅IDを検証
                                         ↓
              駅名・都道府県・路線・代表位置・希望をAIへ
```

- 出発駅と検索先は別の設定です。「出発駅の周辺」を選んでいるときだけ出発駅の変更に追従します。
- ブラウザは既存のlocalStorage、iPhoneは既存のPreferencesに駅IDを保存します。別の駅を探す場合、出発駅を検索サーバーへ送りません。
- 送信内容は `{ stationId, region, theme }`。`region` は「東京都 新宿駅周辺」などの表示文字列です。サーバーは駅IDと表示名の一致を検査し、任意の緯度経度の送信を拒否します。AIへ渡す座標は同梱データの駅の代表位置で、GPS現在地や自宅住所ではありません。
- 旧版の都道府県・自由入力エリアから最寄駅を推測しません。「駅を選択」と案内します。保存済み候補・学習・共同リストをリセットしません。以前のAI検索結果も出典と元の検索条件付きで開けます。別の駅の結果へ勝手に読み替えません。
- 開発用の旧「京都市のみ」検索は別の従来検証です。公開Web・Firebase版iPhoneの駅検索は2社比較を使用します。
- 既存の架空サンプルは実検索と区別します。未選択時は操作用サンプル、駅選択時は設定した架空エリアに該当するものだけです。サンプルの配置を実施設の座標として扱いません。

### 更新・再生成

まず同じコミットの `out/main/csv.zip` をダウンロードします。ファイル取得と生成を分け、スクリプト内のSHA-256と一致しないアーカイブは拒否します。

```bash
python3 scripts/import-rail-stations.py /path/to/csv.zip
git diff -- src/data/rail-stations.json
```

新しい版へ更新するときは、ライセンス・廃止フラグ・IDの変更を確認し、コミット・版・チェックサムもレビューして変更します。既存の駅IDがなくなった場合は選び直しを案内し、近くの別駅へ自動置換しません。

## 費用・未対応

駅候補は端末内で検索するため、新しいAPIキー・入力ごとのAPI課金はありません。同梱データ分のアプリ配信サイズは増えます。AIの新規検索は従来どおり有料です。実APIを使う自動テスト、検索回数の追加制限、DBスキーマ変更はありません。

路線での絞り込み、ローマ字検索、GPSからの最寄駅自動選択、距離の実測、全国の駅周辺の検索品質確認は今後の改善です。「車を探す」の地図・GPS・OSM拠点の取得方式は今回変更しません。

検証と確認画像は [レビュー資料](reviews/station-search/README.md) を参照してください。
