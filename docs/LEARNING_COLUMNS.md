更新日：2026-10-02 / Issue #81・#88

「自分がまだ知らないこと」に気づくための短い読み物を、「学ぶ」の上部に追加しました。提供された `UNKNOWN_UNKNOWNS.md` の101項目から6項目を選び、3ジャンル・各2本を追加し、#88で「運転の再開」の1本を加えました。現在は4ジャンル・計7本です。

## あなたに確認していただく3操作

1. 下部の「学ぶ」→「出発前の準備」「道中の判断」「同乗者との過ごし方」を順に押す。それぞれ2本、新しい「運転の再開」は1本、「すべて」は7本になります。
2. 気になるパネルを押す。「こんな場面」→「最初に、これだけ」→3つの説明→「次のお出かけ前に」までスクロールして読めます。写真は既存のイメージ写真です。
3. 下の「コラム一覧へ戻る」または上の矢印で戻る。選んだジャンルと一覧の位置が残ります。ブラウザを再読み込みしてもURL内のジャンルは残ります。

Macのブラウザ：http://127.0.0.1:5173/#/learn

iPhoneシミュレーターは今回の版へ更新後、Drive+ Mock →「学ぶ」で確認できます。実機への反映は [iPhone開発手順](IOS_DEVELOPMENT.md) の `npm run ios:sync` → Xcodeの▶です。ブラウザの更新だけでは、既にインストールしたiPhoneアプリは更新されません。

## 編集で調整したこと

- 「間違えたら必ず直進」ではなく、その場の信号・標識・車線指定を守る説明に変更。
- 「予約で駐車難易度が確定」とせず、利用条件と空き状況・駐車操作を区別。
- 借りた車のシフトや駐車ブレーキを、場所確認のために不用意に操作するよう案内しない。
- スマホは固定しても注視できるわけではない。原稿の「信号待ちでも法律上は原則不可」を転載せず、停止中の法的扱いと、操作する場所を先に決める提案を区別。
- 同乗者に情報確認を頼んでも、運転者の安全確認・進路判断の代わりにはしない。
- 集中の合図は短い言葉。手を離す合図を勧めず、体調や危険の知らせを我慢させない。

参考資料は2026-10-01に確認しました。引用の寄せ集めではなく、各資料が支える範囲を本文下に記載した独自の説明です。

- [JAF：レンタカーの予約時と返却時の注意点](https://jaf.or.jp/common/kuruma-qa/category-drive/subcategory-rental/faq135) — 慣れない車を借りるときの注意。具体的な操作は車両の説明書・貸出元で確認。
- [タイムズ：駐車場予約の利用ガイド](https://times-info.net/reserve/guide/) — 料金・車両制限・予約条件を確認する例。全施設共通の条件とは扱わない。
- [NEXCO東日本：逆走にご注意を](https://www.driveplaza.com/safetydrive/happening/reverse.html) — 高速道路で出口を通過した場合の対応。
- [警察庁：運転中のスマートフォン・携帯電話等使用](https://www.npa.go.jp/bureau/traffic/keitai/info.html) — 画像注視の禁止と安全な場所に停車してから使う案内。

**公式資料を参照したことと、教材が専門家の監修を受けたことは別です。** 全7本を「試作・未監修」と表示しています。同乗者の2本は提供原稿をもとにした会話例・準備の提案で、効果を証明する研究があるようには表示していません。一般公開前の監修・承認は #9、配信・版管理は #25 の残作業です。

## 仕組み・費用・保存への影響

- 本文とジャンルは `src/data/learningColumns.ts`、画面は `src/screens/LearningColumns.tsx` に分離。既存の Header・Chip・Tag・PrimaryButton とナビゲーションを再利用。
- 一覧は `/#/learn?genre=preparation` など。未知のジャンルは「すべて」へフォールバック。詳細は `/#/learn/columns/parking-entrance` など。不明IDには一覧への案内を表示。
- ジャンルはURLで保持。同一タブ内の戻る操作では既存のスクロール・フォーカス復元を利用。別タブに移動して改めて「学ぶ」を押すと「すべて」から開きます。
- 本文・画像は同梱。追加API・有料サービス・自動の外部送信なし。参考資料は本人が押すとWeb版では別タブ、iPhoneではシステムのブラウザ画面で開きます。
- 保存データの形式は変更しません。閲覧でクイズ回答・学習メモ・学習履歴・保存候補を変更しません。既存の教材と知識チェックはコラムの下に残っています。
- 読了記録・全文検索・全101本の掲載・自動生成は今回は追加しません。
