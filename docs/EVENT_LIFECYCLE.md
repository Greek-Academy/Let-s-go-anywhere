# お出かけ情報の開催状態・確認期限（#18の先行部分）

終了・中止・延期・確認期限切れ・掲載停止を、おすすめ、保存一覧、詳細で同じ判定から扱います。追加API・サーバー・有料サービスは使用していません。全データと根拠は架空のサンプルです。

## 型と責務

- `src/domain/outingLifecycle.ts`：時計を引数に取る純粋な判定、今週末の期間判定、重複候補抽出。
- `src/domain/dates.ts`：日本時間の日付と、秒・タイムゾーンを含む実在日時の検証。#17の入力ツールと共用。
- `Outing.lifecycle`：名称・場所・開催日時ごとの確認状態／情報源ID／確認日／再確認期限、開催単位、掲載状態、写真の条件を保持。
- `src/content/ContentProvider.tsx`：画面の再描画時、表示中の30秒ごとのタイマー、フォーカス／表示復帰で時計を読み直す。
- `OutingStatus` / `OutingImage`：共通の状態表示と写真表示。保存するのは従来どおり候補IDで、状態や写真のコピーは保存しない。

この型は**検証済みのカタログを受け取るための型**で、任意のAPI/JSONを受け付ける入力バリデーターでも、公開承認機能でもありません。現行のContentCatalogは引き続き`source: sample`だけです。写真の条件は公開側で必要な状態に絞った想定で、権利者・許諾記録などの私的なメモは含めません。#17の入力JSONからの自動変換はありません。

## 判定の意味

| 入力・時点 | 表示・動作 |
| --- | --- |
| 開始前／開始時刻以降・終了時刻未満 | 開催予定／開催中。確認条件を満たす場合のみおすすめに含める |
| 終了時刻ちょうど以降 | 終了。おすすめから外し、保存と詳細に状態を残す |
| 中止／延期の明示 | 時刻や期限が変わっても中止／延期を維持。以前の日程を現行日程として表示しない |
| 確認期限当日 | 日本時間23:59:59まで有効。翌日から要確認 |
| 日時・開催年・会場の不足／不整合、確認日が未来、根拠の欠落 | 要確認。日時を推測して埋めず、おすすめから外す |
| 情報全体の掲載停止 | おすすめから外す。直接URLでも紹介本文・写真・下見情報を表示しない。保存IDは削除しない |
| 写真の利用停止／期限切れ／参照不可 | img要素にURLを渡さず、代替表示。読み込み失敗時も代替表示 |
| 写真停止後、情報に独立した根拠が残る | 文字の情報は継続可能。写真の停止だけでは情報全体を停止しない |
| 参照先を失い独立した根拠もない | 情報は要確認。おすすめに戻さない |

要確認が終了判定より優先する場合があります。期限切れになった古い開催日だけを使って終了を断定しません。中止・延期・掲載停止の明示が最優先です。

今回の保守的なサンプル判定では、名称・場所・開催日時それぞれに、参照可能な公式情報または施設・現地確認の根拠を要求します。SNSは発見元として分けて残します。これは自動で情報の真偽や許諾を保証するものではありません。

「今週末」は日本時間の当該週の土曜00:00から月曜00:00まで。日曜日にはその週の土日を扱います。開催期間との重なりがあり、まだ終了していない対象だけを含めます。固定の`weekend`フラグは廃止しました。

## 重複候補

`duplicateCandidates()`は、確認が有効で、シリーズID・会場ID・開始年（日本時間）・開始／終了の時点がすべて一致する候補IDの組を返します。UTCと日本時間表記が違っていても同じ時点なら一致します。

別年度・別会場・時間が異なるもの、日時未確認のものをまとめません。タイトルの似かよいだけでは判断しません。元のレコード・複数投稿・確認根拠は変更も削除もしません。候補確認画面、承認を伴う統合、保存IDの統合先対応は後続です。

## 画面確認

[確認手順・画像](reviews/event-lifecycle/README.md)を参照してください。通常ホームでは6件の候補が2026-09-16時点で表示されます。終了・中止等の確認用レコードは直接URLから開きます。日付の経過とともに候補が減るのは意図した動作です。端末時計や保存データを変更する必要はなく、境界時刻はPlaywrightの時計で検証します。

## 今回含まないもの・担当の境界

開発の後続：#17の本番承認状態を取り込む検証済みアダプター、重複候補の審査・統合、再確認ジョブ、訂正履歴、配信キャッシュ削除、APIによる最新状態取得と更新通知。

人間の後続：#12の更新担当・確認期限・訂正／再開ルール、#17の承認、#43の施設選定と写真利用条件の確認。今回入力した期限はモック用で、実運用の期限や承認を決定していません。

静的モックは読み込んだカタログ内の状態と端末時計だけを評価します。外部の削除・権利申し出を検知せず、既に取得したファイルやブラウザ／CDNのキャッシュも消去できません。再配信したカタログはページ再読み込み後に反映されます。開いたままの画面の時刻反映は通常最大30秒、バックグラウンドでは表示復帰時です。リアルタイムな掲載停止の本番完了条件は未達のため、#18は閉じません。
