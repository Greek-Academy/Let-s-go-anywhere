# Drive+：今できることと、次に進めること


2026-10-04更新：確認済みのPR #89・#92・#95をマージしました。#94で別アカウント同士の招待・候補・反応をFirebaseへ接続し、HTTPSで相手のSafariから参加できる検証版を準備しています。[確認する3操作](SHARED_WISHLIST_CLOUD.md)。

## いま確認すること — #94

自分のメールでログイン→共有リストを作成→招待リンクを相手に送る→参加申請を承認→二人で候補と反応を持ち寄る流れです。人間側は確認相手1人を用意し、実際のスマホ同士で表示を確認します。一般公開・アカウント全削除・不正利用対策等は親 #40 に残します。

## 直前の方針変更 — #88

**アプリ内での講習会社の紹介・比較・相談受付を終了します。** 下部は「見つける／行きたい／車を探す／学ぶ」の4タブです。「学ぶ」には、久しぶりの運転に備えてペーパードライバー講習を検討するための読み物を追加します。会社の推薦・申込み・送客は行いません。[変更範囲と旧データの扱い](LESSON_REFERRAL_RETIREMENT.md)。

2026-10-02の利用者の指示により、旧PRDの講習紹介・相談・成果照合を公開の必須条件から外します。今回の変更を本番公開や専門家監修の完了とは扱いません。以前の画面・5タブの検証画像は、当時の記録として `docs/reviews/` に残します。

## 次に進める順序

1. **本人用の保存を確認し、相手との共有へ進む — #93・#94。** #91の準備と#93の実クラウド検証は完了。本人のメールで登録・保存を確認し、#94で招待・候補・反応を接続します。#88の4タブと学ぶを維持します。
2. **今ある4機能を実機・文字拡大・通信失敗でも使いやすくする — #32・#68。** 費用をかけずに先行できる改善を、小さなIssueに分けます。
3. **本物の情報で試す範囲を絞る — #7・#8・#9・#17〜#22・#24・#25・#71。** スポットの根拠・写真、地図と拠点の更新、教材の監修を確認します。先行施設の選定・写真許諾は、利用者の指示により当面後回しです。
4. **必要性と費用を確認して本番接続する — #5・#6・#13〜#16・#29。** 認証・保存・削除・権限を一緒に設計します。予算は初期費用を含む累計3,000円以内です。

共同リストの本公開対応、休日プラン、SNS自動収集、通知は後続として残します。公開判断・規約・情報の利用条件・専門家の監修を、コードの実装だけで完了にはしません。

## 直前の4タブ変更で確認する操作

1. **4タブ：** 見つける → 行きたい → 車を探す → 学ぶ。プロフィールと設定に会社相談の入口がないことを確認します。
2. **新コラム：** 学ぶ → 運転の再開 → パネル → 本文を読む → 戻る。文章が分かりやすく、無理に運転を促していないか確認します。
3. **学習メモ：** 学ぶ → 学習メモを開く → 入力 → 別のタブ → 再度開く。以前のメモも残り、外部へ送信されないことを確認します。

開発中のブラウザは `http://127.0.0.1:5173/`。URLのホスト・ポートが違うと保存場所が分かれます。iPhone版は `npm run ios:sync` → Xcodeの▶で更新します。[iPhone開発手順](IOS_DEVELOPMENT.md)。
