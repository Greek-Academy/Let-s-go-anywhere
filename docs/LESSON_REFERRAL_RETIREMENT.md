# 講習紹介を終了し、「学ぶ」に運転再開の読み物を置く

2026-10-02 / Issue #88。今回の利用者の指示を、旧PRD v0.2の講習紹介・相談に関する要件より優先します。

## 何が変わるか

下部タブは **見つける → 行きたい → 車を探す → 学ぶ** の4つです。講習会社の一覧・比較・講師詳細、希望日時の相談、共有確認、受付デモ、相談履歴を削除しました。お出かけ詳細、チェック結果、プロフィール、設定からも会社紹介へ進むボタンはなくなります。

「学ぶ」の最初に、既存と同じ写真パネルで「久しぶりの運転は、ペーパードライバー講習で練習しよう」を追加しました。「運転の再開」で絞り込めます。講師と練習する選択肢、希望・不安の伝え方、料金や車両など申込前の確認事項を説明する読み物です。アプリから会社を選ぶ、申し込む、情報を送る機能はありません。

## 残る機能と保存データ

- お出かけと車の保存、プロフィール、知識チェック、学習履歴、コラムを維持します。知識や不安の整理を、実技の採点・安全の保証には使いません。
- 教材で追加した質問メモは、本人用の **学習メモ** として「学ぶ」「マイページ」「設定」から読んで編集できます。旧版の `memo.questions` をそのまま使うため、既存のメモを移し替える必要はありません。
- 振り返りの新規入力は「お出かけ／練習」です。過去の「講習」区分や助言の記録も消さずに読めます。
- `consultations` と `schoolFilters` は、旧版データを壊さず読み書きできるよう、保存形式の検証だけに残します。新しい相談は作らず、表示・送信・集計・サーバー同期には使いません。`memo` の目標・旧入力項目も勝手に削除しません。
- 設定で保存データ全体を削除する場合は、これらの旧データも削除対象です。元データの取り出しと破損時の保護は従来どおりです。

旧 `/schools/*`、`/consult/*`、`/consultations/*`、`/profile/consultations` は履歴を置き換えて `/learn?retired=schools` へ移り、終了の案内を表示します。古いリンクから相談フォームが復活したり、戻る操作で同じページを行き来し続けたりしないよう検証します。

「対応不要」は機能を実装して完了したという意味ではありません。閉じたIssueの説明・議論は履歴として残し、他のIssueの公開条件からは講習会社連携を外します。共同リストでの本人情報の非公開方針は維持します。

## 今後、人間が行うこと

新コラムの読みやすさ・内容の確認と、一般公開前の専門家監修（#9）は引き続き必要です。今回、講習会社との提携契約・紹介料の決定・相談受付先の準備は不要になります。公開範囲、掲載情報・写真の利用条件、個人情報の扱いなど、他の機能の準備は継続します。

## 確認手順

1. 下部が4タブで、マイページや設定に講習相談のメニューがないことを確認。
2. 「学ぶ」→「運転の再開」→パネルを開き、本文を下まで読む→一覧へ戻る。
3. 「学習メモを開く」で記入し、別のタブへ移動して戻る。メモが残っていることを確認。
